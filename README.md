# Divine Foam & Mattress — Website

A React, TypeScript, Vite and Three.js website for Divine Foam & Mattress, Nadiad, Gujarat.

## Development

- Install dependencies with `npm install`
- Run the local development server with `npm run dev`
- Create a production build with `npm run build`

## Deployment

The production website is built by the GitHub Actions workflow at `.github/workflows/deploy.yml`. The workflow publishes the generated `dist/` directory to GitHub Pages. The repository Pages source must be set to **GitHub Actions**.

The site is configured for the repository URL path `/divine-foam-3d/`.
